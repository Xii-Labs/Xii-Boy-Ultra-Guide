The following is a writing style guide for contributors to the Xii-Boy Ultra Guide.

These rules ensure the guide maintains the same tone and style throughout steps and sections.

# Rules

- Start every instruction with a direct verb (e.g., "Retrieve," "Align," "Fasten," "Apply"). Avoid introductory fluff or passive phrasing.

- Strictly avoid the use of "you," "your," "me," or "I." Keep an objective, third-person perspective.

- Use formal writing throughout the guide. Do not use slang, contractions, or casual language.

- Always reference the exact source of a component (e.g., Bag G2, Bag B4) and use precise technical names for parts (e.g., Main PCB, 8 Pin FFC, Xii-DD).

- Never use vague terms like "some" or "a few." Specify the exact count, length, etc. (e.g., "five 4mm Phillips screws").

- Always provide a "Why" for safety or critical steps. Explain the consequence of a potential error (e.g., "it will cause a short," "this could crack the shell") to ensure the user understands the stakes.

- Many users will be beginners, so avoid assuming prior knowledge of electronics or tools. Define terms and explain concepts clearly.

Have fun, and thank you! Happy modding!
